## Current workflow

Start with [current-state.md](current-state.md). Select an existing run with `./unit9 motion-use full-run-ti36vxyf`; use `motion-status` and `motion-preflight` before expensive work. The selected run is visible in status; `motion-use default` clears it.

Once source checks pass, review registration changes and render intentionally. `motion-finish` then performs validate → timeline → assemble → check → conform → package → package-check, stopping on failure and using the exact package returned by packaging. It does not render handled shots.

The prior `conform_first_frame_offset: 1` setting is a documented reference exception, not a corrected continuous movie. New receipts retain excluded first-frame measurements and report `passed_with_exclusions` when they differ. Such evidence requires explicit first-cut review and is not complete boundary fidelity.

## Reproducibility and archives

The toolkit checkout does not contain the complete Unit 9 source film; it depends on the sibling `../nonsense` tree. A collected handoff supports editorial work but is not a source backup. Preserve the original recording, native and SVG source/assets, saved cues, edit data, project configuration, `.sbph/` records, and locked toolkit version before testing restoration elsewhere. Do not delete the only working environment or modify the original film merely to satisfy a checklist.

The unrelated `bone-app-svg-collection.zip` is retained as owner inventory, not a runtime dependency. `docs/history/package-manifest-legacy.json` preserves the retired root inventory and is not an integrity gate; current packages use `handoff.json`. No archive deletion or Git history rewriting is required to finish the local tool.

## Known deliberate limits

- Framework source changes invalidate every handled-shot build; selective invalidation remains a measured future optimization.
- Caught failures/cancellation have staged recovery; forced kills and power loss are not promised atomic.
- Offline basename associations are presumed, not verified returned media bytes.
- Human timing, creative acceptance, device playback, and real editor behavior require their own evidence.
